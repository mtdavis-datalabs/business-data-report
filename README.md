## Business Performance Report with Data Visualisation


## Overview
A professional two-page business report presenting retail sales analysis findings 
(built on the Sales Performance Dashboard project) for a non-technical senior 
management audience.

## What This Demonstrates
- Translating data findings into clear business language
- Professional written communication and report formatting
- Data-driven recommendations for business decision-making

## Tools Used
Microsoft Word — report writing, formatting, table of contents
Microsoft Excel — source charts and analysis (see sales-dashboard repository)
